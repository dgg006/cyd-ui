# Seguridad

No publiques `secrets.yaml`, tokens de Home Assistant, contraseñas MQTT ni
configuraciones con entidades privadas. El repositorio ignora esos archivos,
pero cada usuario debe revisar sus cambios antes de publicarlos.

Para informar una vulnerabilidad, abrí un aviso privado mediante la sección
**Security** del repositorio. No incluyas credenciales reales en un issue.
