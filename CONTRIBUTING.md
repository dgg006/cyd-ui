# Contribuir

CYD UI está en desarrollo temprano. Antes de proponer cambios:

1. Conservá el desacople entre el firmware y Home Assistant.
2. No agregues entidades ni credenciales dentro del firmware.
3. Mantené los widgets precreados y actualizá propiedades en ejecución.
4. Añadí o actualizá pruebas para los cambios de contrato.
5. Ejecutá `python -m unittest discover -s tests -v`.

Los errores y propuestas pueden registrarse mediante GitHub Issues.
